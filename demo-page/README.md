# E2E Self-Heal demo page

A presentation page that replays how the engine repairs selector drift and refuses product
regressions, compares look-alike scenario pairs, and shows the safety-benchmark metrics.

```bash
pnpm install
pnpm dev        # http://localhost:4174 (the examples demo app uses 4173)
pnpm build      # typecheck + production build into dist/
```

## What is real and what is an example

The page marks every block as **measured** or **example**.

- **Measured** — `src/data/demo.json`, generated by `scripts/build_data.py` from each scenario's
  `spec.ts`, `change.patch` and `meta.json` under `examples/scenarios/`, the Playwright failure
  logs in `scripts/logs/` (captured against the demo app with each patch applied), and the actual
  output of the engine's Error Log Parser and Diff AST Analyzer. The `id-rename` engine run is the
  real NVIDIA NIM run recorded in the repository README.
- **Example** — every other engine run in `src/runs.ts`, shaped after the real log events and the
  refusal-reason branches in `app/graph.py`, and the benchmark figures computed from them.

Regenerate the data after a scenario changes (`pnpm data` from this folder). To refresh a failure
log, apply the scenario's patch, run its spec with `--reporter=line`, and save the output as
`scripts/logs/pw-<scenario>.log`.

## Languages

Simplified Chinese is the default across the replay, comparisons, safety metrics and architecture.
English, Korean and Japanese remain available in the header. The language picker stores the choice,
and `?lang=zh|en|ko|ja` links to a specific one. The versioned preference key starts earlier visitors
in Chinese too; subsequent explicit language choices are remembered.

Strings live in `src/i18n/<lang>.tsx`. `en.tsx` defines the shape (`Dict` in `types.ts`, and the
step-note keys), so a key missing from any locale is a type error. To add a language, copy
`en.tsx`, translate it, and add it to `LANGS` in `src/i18n/index.tsx`.
